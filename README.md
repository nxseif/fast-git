# FastGit

Small bash script for automation of common git commands.

Instead of writing:

```bash
git add
git commit
git push
```

I just run:

```bash
./fastgit.sh filename
```

Script checks the  file adds commits and pushes it on github

## Technologies

* Bash
* Linux
* Git
* Github
